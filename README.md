# Smart City Santa Elena · Prefectura Luis Orrala Rodas
Sitio estático (HTML/CSS/JS) que une: páginas del candidato, la plataforma Santa Elena Participa (carpeta `participa/`) y los minijuegos educativos (submenú Minijuegos).

## Estructura
- `index.html`, `css/`, `js/`: sitio principal y minijuegos.
- `participa/`: plataforma de participación ciudadana y observatorio (se muestra dentro del sitio).
- `assets/campana/`, `assets/puzzles/`: imágenes.

## Publicar en GitHub Pages
Sube el contenido de la carpeta a un repositorio → Settings → Pages → rama `main`, carpeta `/ (root)`.

## Editar
`js/site.js`: textos, menús y contacto (`SITE.contacto`). Participa se configura en `participa/js/config.js`.
